# ミルスコープ

iPhoneのSafariで動く単一HTMLの測距ツールです。カメラ映像または選んだ写真にミルレティクルを重ね、大きさが分かっている対象の両端に赤い2点を合わせると、その対象までの距離を計算して表示します。

- アプリ: https://hanaphoto.github.io/mil-scope/
- 使い方ページ: https://hanaphoto.github.io/mil-scope/manual.html

> 元はClaudeのArtifact「ミルスコープ」として作られたものを、GitHub Pagesで公開したものです。アプリの操作パネル下部に説明書へのリンクを1行追加しています（公開時に加えた変更はそれだけです）。

## 計算の仕組み

- 距離（m）＝ 対象の実寸（m）× 1000 ÷ 対象のミル数
- 1ミルは約1/1000ラジアンで、1km先で1mの大きさに相当します
- 未校正のときは、iPhone標準カメラの水平画角を65°と仮定して計算します（目安です）
- 校正すると精度が上がります。大きさと距離が分かっている物（例：10m先の1mの物差し）を映し、赤い2点をその両端に合わせて「この2点で校正」を押します。校正値は倍率1倍あたりの値として保存され、ズーム倍率と連動します

## モード（レティクル）

| モード | レティクル | 対象プリセット |
|---|---|---|
| 猟 | 中央を少し空けた十字線＋1ミルごとのドット＋外周の太いポスト | ニホンジカ 肩高0.9m／イノシシ 肩高0.7m／人（確認用）身長1.7m／カスタム |
| 競技 | 1ミル目盛り＋細目盛り＋ホールドオーバー用ドット格子 | IPSC標的 幅0.45m・高さ0.75m／スチール 直径30cm／クレー 直径0.11m／カスタム |
| 撮影 | 細い目盛りと数字のみ | 人 身長1.7m／乗用車 全幅1.8m・全高1.5m／サッカーゴール 幅7.32m／カスタム |

## 使い方

1. 「カメラ」を押してカメラを許可するか、「写真を選ぶ」で撮影済みの写真を表示します（カメラ映像は「静止」で止めて測ることもできます）
2. 対象プリセットを選ぶか、実寸（m）を直接入力します。ズームを使った場合はズーム倍率も合わせます
3. 赤い2点をドラッグして対象の両端に合わせると、距離（m／ヤード併記）とミル数が表示されます
4. 「色」ボタンでレティクルの色を4色（黄・赤・白・水色）から切り替えられます

## 動作環境

- iPhoneのSafari（カメラを使う場合はカメラの許可が必要。位置情報は使いません）
- 実機での十分な検証はこれからです。表示される距離は目安であり、安全確認の代わりにはなりません

## 注意点

- 精度は「実寸の正しさ」と「2点を両端に正確に合わせること」と「校正」に依存します。実寸がずれると距離もその割合でずれます
- ズーム倍率の欄は計算用の入力です。映像を拡大したら、その倍率を入力してください（カメラのズームと自動では連動しません）
- 未校正の値は画角65°の仮定です。機種やレンズ（超広角・望遠など）が違うと誤差が大きくなります

## プライバシー（公開前の確認結果）

公開に先立ち、アプリの中身を2026-11-20に確認しました。

- 個人名・連絡先・特定の地名・住所・秘密情報は含まれていません
- 外部送信の仕組みはありません。カメラ映像と選んだ写真は端末の中で処理され、外部へ送られません
- 外部ファイルの読み込みもありません（フォント含め全て単一HTML内）
- ブラウザに保存されるのは、モード・レティクルの色・校正値の3点だけです（localStorageのキー `mil.s`）。対象の実寸やズーム倍率、写真そのものは保存されません
